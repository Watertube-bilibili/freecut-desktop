# 内置原创合成音效

FreeCut 的 16 种内置音效由 [electron/sound-library.cjs](../electron/sound-library.cjs) 在本机生成。音效不使用录音、网络音效包、剪映素材或第三方采样；没有模型下载，也不会上传项目素材。

来源是本项目原创的数学合成程序：正弦振荡、线性扫频、确定种子的伪随机噪声、简单低通平滑及振幅包络。提示音使用短促的独立音高组合，不取自现有歌曲。每个声音以固定版本和种子生成 48 kHz、单声道、16 位 PCM WAV，峰值限制在满刻度的 65%，开头和结尾附短淡入淡出。

生成器代码遵循本项目的 GPL-3.0-or-later。FreeCut 贡献者将该生成器产生的原始内置音效文件以 **CC0-1.0** 提供，可以用于商业或非商业项目，无需标注 FreeCut。CC0 不改变用户加入的其他素材或最终作品的权利，也不提供对所有用途的法律保证。完整说明参见 [Creative Commons 的 CC0 文本](https://creativecommons.org/publicdomain/zero/1.0/legalcode)。

| ID | 名称 | 时长（秒） | 合成方法 |
| --- | --- | ---: | --- |
| click | 轻快点击 | 0.12 | 噪声与短促高频正弦 |
| tap | 柔和轻敲 | 0.22 | 双振荡器指数衰减 |
| pop | 气泡弹出 | 0.24 | 下降扫频 |
| snap | 清脆拍点 | 0.14 | 噪声差分与快速衰减 |
| confirm | 完成提示 | 0.70 | 三个依次触发的独立音高 |
| notify | 消息提醒 | 0.80 | 基频与倍频指数衰减 |
| warning | 注意提示 | 0.65 | 两个依次触发的独立音高 |
| error | 低落提示 | 0.60 | 两个下降音高的衰减声 |
| swoosh | 空气划过 | 0.70 | 平滑噪声、高频扫频和高斯包络 |
| rise | 电子上升 | 1.10 | 上升扫频与平滑噪声 |
| fall | 电子下降 | 0.90 | 下降扫频与平滑噪声 |
| impact | 低频落点 | 0.50 | 低频正弦与快速噪声瞬态 |
| sparkle | 闪光点缀 | 1.20 | 四个依次触发的高频衰减声 |
| tick | 短促节拍 | 0.09 | 高频正弦与快速衰减 |
| shutter | 机械双击 | 0.25 | 两次短噪声包络 |
| chime | 柔和钟音 | 1.60 | 三个振荡器与较长衰减 |

文件按需写入应用数据目录的 `sounds-v1/`，并通过正常素材导入流程获得访问权限。缓存文件若被修改，会由确定性的生成结果重新生成。模型、FFmpeg 和 Electron 的许可证不属于这些原创声音的来源，仍分别按 `THIRD_PARTY_NOTICES.md` 的说明提供。
