# FreeCut 验证记录

本记录区分源代码测试、实际桌面交互和原生模型推理。一次成功不代表所有素材、硬件或长项目均已验收。

## 0.3.0 直接预览操作、声音与分发更新

2026-09-07，Windows x64 / Electron 44.2.0，本次本机验收记录如下；三平台最终构建及准确提交以 [0.3.0 Release](https://github.com/Watertube-bilibili/freecut-desktop/releases/tag/v0.3.0-preview.1) 关联的 Actions 为准。

- `npm test`：111 项前端核心测试、73 项 Electron 宿主测试、14 项安装器后端测试通过，共 198 项；Windows 跳过 1 项仅适用于 macOS 的测试。包括预览变换、蒙版路径、音频矩阵、分段模型下载、更新 SHA-256 与重试、安装清单及回滚。Windows 实际 PowerShell 便携更新 helper 在宿主测试中替换临时可执行文件，覆盖正常启动、启动失败回滚、校验失败和中文路径；真实 Node / Electron 父进程退出后，后台更新仍完成替换和启动。
- `regression-transform.cjs`：10 组真实 Electron 交互通过。点选、拖动、缩放、旋转、锁定/隐藏保护、一次手势一次撤销、Esc 取消、关键帧编辑、手机布局与工程持久化。
- 关键帧和预览变换回归使用真实保存完成状态：通过显式暂停、释放最近工程索引提交，复现“工程已落盘但 IPC 尚未完成”的时间差，确认此时键盘/坐标点击被保存保护拦截；等待保存遮罩消失后再执行原有严格操作断言。没有通过固定延时或放宽坐标断言掩盖问题。
- `regression-effects.cjs`：7 组通过。7 种正反蒙版、羽化、叠加轨道像素、视频变换关键帧的预览/严格导出一致性、调色重置、保存重开，以及短窗口/手机布局最下方控件的可访问性。
- `regression-audio.cjs`：16 组 Web Audio 实际 PCM 与 FFmpeg 混音输出对照通过，覆盖立体声、仅左、仅右、单声道、交换、平衡及增益。16 种原创音效均经真实 FFmpeg 导入验证。
- `regression-sounds.cjs`：真实音效库显示全部 16 项，试听、重复加入同一音效并保存工程通过；2 个片段共用 1 份素材记录，避免重复素材 ID 破坏工程。
- `regression-update.cjs`：6 组真实应用更新流程通过。测试仅控制官方 GitHub URL 的网络响应、原生对话框回答与最后的安装器启动替身；使用真实下载分段、散列、主进程、preload、界面和工程原子保存。设置持久化、忙碌延后、倒计时、取消后继续编辑、保存取消/失败保护、保存成功后仅启动一次均通过。该测试不等于在用户机器上执行真实升级。
- `installer/smoke.cjs`：4 组真实自定义安装 UI 通过，包含 C/D 一键入口请求、自定义根目录补全、真实临时载荷安装、取消/重试和 PowerShell 卸载。C/D 请求在此测试中截获，避免改写实际用户目录；临时安装使用独立目录。后端新增单运行环境的原位载荷准备、原始 app.asar 字节保持和损坏载荷拒绝测试。
- `installer/smoke-setup.cjs`：实际 Setup 文件的 4 组测试通过。独立中文路径安装 36 个文件并核对 SHA-256，启动安装后的编辑器，再由应用触发卸载；应用退出后，后台卸载删除清单内文件并保留用户文件。正式 CI 对发布产物重复此检查。macOS CI 另验证原生更新替换/回滚与实际更新 ZIP 的目录、签名、版本、架构。
- Windows 卸载快捷方式回归：旧逻辑的 8.3 路径别名及英文 Windows 下 WScript 读取中文乱码均已复现。现通过 `IShellLinkW` 读取 Unicode 属性，先按文件句柄规范路径确认归属，检查属性和执行标志并记录散列，删除前再次复验。独立测试进程实际使用 ACP1252，直接编译生产读取器核对 8 条真实快捷方式的中文信息；3 条归属当前安装的默认快捷方式清理成功，不同目标、自定义参数、目录链接、管理员运行和兼容执行的 5 条快捷方式保持散列不变。
- 既有首页回归 11 组、编辑器回归 5 组、真实视频预览回归 7 组仍通过；快速定位/布局变化采样未观察到黑帧。TypeScript 和生产构建通过。

SenseVoice 在原公开 0.2.0 应用、中文路径和补丁打包应用中完成实际运行环境/模型安装、散列检查及中文识别。用户报告的“下载完成后立即报错”未在本机复现；因此本版记录为下载完整性、恢复和诊断加固，不宣称已复现并确定其唯一原因。下载测试只用固定上游文件与独立临时 profile，不修改已有用户模型。

公开分发使用三平台源码构建 FFmpeg；本地快速打包的供应商引擎不作为正式 Release 引擎。依赖许可核对见 [DEPENDENCY-LICENSE-AUDIT.md](DEPENDENCY-LICENSE-AUDIT.md)，品牌与模型等边界见 [RELEASE-REVIEW-030.md](RELEASE-REVIEW-030.md)。未验证事项包括所有硬件/媒体组合、长片压力、Mac AI 模型真实推理以及正式代码签名/公证。

宣传片的真实媒体检查与来源记录独立保存在 `videos/shuiguan-launch/QA.md` 和 `SOURCES.md`，不把动画宣传画面当成软件功能测试。

## AI 剪辑 Skill

`skills/shuiguan-cut` 通过 `quick_validate.py`。Windows 本地源码模式与实际打包应用模式均完成 5 秒素材导入、工程保存和真实应用 UI 导出；横屏 1280×720、竖屏 720×1280 / 24 fps 成片严格完整解码，自动化实例的更新服务关闭、配置目录隔离。独立智能体使用另一组原创视频及双声道音频完成 6 秒、720×720 / 25 fps 配方，逐像素核对入点、半速播放、位置关键帧与中文文字，并对音频核对左右交换、独立增益与音量关键帧；全新应用配置下重新打开和保存工程正确。

输出目录已存在时拒绝执行，原 7 个文件的散列保持不变；未知字段明确拒绝并写失败报告，不生成 MP4。脚本本身不替代产品渲染器。Mac 与 Windows CI 对同一 Skill 再执行真实应用自检，结果以 Release 关联构建为准；尚未宣称桥接所有软件功能。
