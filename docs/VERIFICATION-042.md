# 0.4.2 验证记录

日期：2026-09-15。状态：本地真实 ChatTTS 迁移及合成、模型目录后端回归、8 组真实桌面目录回归、三个平台构建及打包应用检查均已通过；公开发行上传与下载核验随后补充。已有 0.4.1 或更早版本的测试和安装包结果不计作 0.4.2 已通过。

## 本次范围

0.4.2 新增自定义朗读模型下载目录。在“AI 语音 → 语音朗读”选择父目录后自动创建 `FreeCut-VoiceModels` 子目录，供 ChatTTS、轻量 AISHELL 中文朗读模型和后续模型下载缓存使用。已完整安装的模型复制并校验成功后才启用新目录，源文件保留；失败保持原配置。旧下载缓存和未完成文件不复制，保留原位。下载或生成期间禁止切换，可恢复默认，配置跨次启动保留，支持中英文界面。

Python、sherpa 运行环境、已生成音频与 SenseVoice / Whisper 自动字幕模型仍保留原位置。本次不移动整个用户数据目录，不增加其他编辑功能，也不更改模型来源和许可。

## 适用范围

目录切换采用复制，成功后不自动删除原模型文件，所以复制时需要为新旧两份文件预留空间，也不会立即回收旧目录空间。自定义到其他磁盘的目录需要持续可用，不会随便携程序自动移动。

真实 ChatTTS 目录迁移与生成的测试入口为 `scripts/smoke-voice-storage.cjs`，结果见 [本次模型验证摘要](verification/042-voice-storage.json)。Windows / Electron 44.2.0 使用已有测试缓存，复制校验到中文和空格目录耗时 5.848 秒；重新创建服务后从磁盘配置恢复新位置。临时隐藏旧模型目录时仍能实际生成 1.86 秒非静音 WAV，并由 FFmpeg 导入为音频，证明使用了新目录。合成及导入耗时 52.595 秒；这不是语音性能或自然度承诺，也未做本段语音内容的转写核对。原运行环境标记和已有音频逐字节不变，测试结束恢复原模型目录和默认配置。

受控文件迁移通过不能代替真实模型推理验收；Windows 上的模型生成成功不能等同于 Mac 已实测。历史 ChatTTS / AISHELL 推理与模型许可说明继续见 [ChatTTS](CHAT-TTS.md)和[字幕与语音模型](AI-MODELS.md)。历史跨网协作结果保留在 [0.4.1 验证记录](VERIFICATION-041.md)，不据此声称本版本已重新跨网测试或所有网络都能连接。
