# FreeCut 功能覆盖与验证边界

本表对应水管剪辑 / FreeCut 0.3.1 的实际代码，更新于 2026-09-07。目标是逐步替代常用剪辑工作流；当前是可运行的早期桌面编辑器，**尚未覆盖剪映的全部功能、素材和 AI 能力**。不能把研究建议、引擎支持的滤镜或界面入口计作已经完成的产品功能。

范围依据为 [桌面调研](../research-desktop.md)、[手机版调研](../research-mobile.md)、[效果与分发调研](../research-effects.md)，实际状态以 `src/App.tsx`、`src/components`、`src/core` 和 `electron` 的实现为准。国内剪映、海外 CapCut 及各平台的会员权益会变化，本文不把海外权益当作国内统一付费清单，也不声称复制任何受限素材。

状态说明：**已实现**表示存在实际编辑或处理路径；验证栏说明已经检查的范围，不能推断所有平台和所有媒体都通过。**部分**表示仅实现该类能力的明确子集。**实验**表示实现已接入但仍有运行验证或质量限制。**待实现**表示目前没有可用处理路径。平台打包配置与实际平台运行分别记录。

## 项目、剪辑与预览

| 能力 | 状态 | 当前实现与边界 |
| --- | --- | --- |
| 本地视频、音频、图片导入 | 已实现 | 原生文件对话框、FFmpeg 探测、素材引用；不修改原文件。导入同一文件按资产 ID 去重。 |
| 广泛格式兼容 | 部分 | 探测支持的容器范围比 Chromium 实际解码范围更宽。预览建议 MP4/H.264 与常用图片、音频；没有代理转码或无法解码时的自动回退。 |
| 多轨与画中画 | 已实现 | 视频、音频、文字/图形叠加；可添加叠加轨道，调整图层变换。没有复合片段或嵌套时间线。 |
| 移动、修剪、分割、复制、删除 | 已实现 | 拖动位置与两端修剪，帧级吸附、撤销/重做。分割保留源入点与动画映射；检查器可更换所在轨道，尚不能直接跨轨拖动。 |
| 轨道锁定、隐藏、静音 | 已实现 | 锁定限制编辑；隐藏只控制画面；音频由静音决定，因此隐藏的视频仍可发声。 |
| 右键菜单与片段剪贴板 | 已实现 | 片段、轨道、预览对象、素材和时间线菜单；复制/剪切/粘贴、复制到片段后、分割、翻转、轨道状态、素材重连。保留关键帧并生成独立 ID，支持撤销和锁轨限制；尚无多选片段、跨工程或系统片段剪贴板。 |
| 播放与定位 | 已实现 | 播放暂停、时间码、逐帧前后、拖动播放头、时间线缩放、跳到关键帧。复杂项目仍受浏览器解码和 CPU 性能影响。 |
| 工程保存、重开 | 已实现 | 版本化 `.freecut` JSON，主进程原子保存；打开后重新校验媒体路径并授权，丢失文件有缺失状态。工程保存的是引用，不内嵌媒体。 |
| 首页、设置与关于 | 已实现 | 我的项目记录最近保存和打开的工程，支持搜索、排序、打开、定位与仅移除记录；设置保存布局/关键帧模式，关于提供版本、B站和源码入口。不会自动扫描磁盘工程。 |
| 未保存退出保护 | 已实现 | 关闭窗口、应用退出、返回首页、新建/打开工程前可保存、放弃或取消。保存对话框取消、保存失败保留当前工程；异步文件操作期间保护当前修改。 |
| 缺失素材重连 | 部分 | 逐个选择缺失素材的替代文件。尚无按目录批量匹配、相对路径工程归档或集中重连管理器。 |
| 自动保存与崩溃恢复 | 部分 | 浏览器写入本地草稿并尝试恢复；桌面目前仍需手动保存工程，不承诺桌面崩溃恢复。 |
| 多时间线、复合片段、多机位 | 待实现 | 需要独立序列模型、多机位同步与切换逻辑；多个轨道不能代替这些功能。 |
| 大工程性能 | 部分 | 串行逐帧导出与缓存预览适合先验证短片；代理、后台缩略图、音频波形、渲染队列、内存预算仍待完成。 |

## 桌面关键帧、效果与文字

| 能力 | 状态 | 当前实现与边界 |
| --- | --- | --- |
| 桌面属性关键帧 | 已实现 | X/Y、统一缩放、旋转、透明度、音量；属性旁按钮、关键帧面板和 `K` 快捷键。实际预览、项目存储与导出使用这些数据。 |
| 普通 / 专业关键帧模式 | 已实现 | 默认普通模式，一键记录画面/音量、整组删除与前后跳转、常用滑块和一键动画；专业模式保留逐项参数和缓动编辑，与工作台布局独立。 |
| 关键帧基础插值 | 已实现 | 线性、缓入、缓出、缓入缓出、保持。时间为片段局部秒数；同一时刻最后写入的值生效；首末点之外保持端点值。 |
| 关键帧编辑 | 部分 | 新增、更新、删除、修改值和插值、点击时间轴菱形定位。尚无曲线图、拖动关键帧时间、复制粘贴整组关键帧、可编辑三次贝塞尔。 |
| 裁剪/分割动画连续性 | 已实现 | 核心函数对切开的插值区间补采样，并重定位右片段时间。分割将现有淡入淡出烘焙到音量/透明度关键帧，保留画面及声音包络；有缓动、重叠淡变和保持跳点的数值回归。局部缓动与淡变采用有界近似。 |
| 几何变换 | 部分 | 位置、统一缩放、旋转、不透明度、水平/垂直翻转。无独立 X/Y 缩放、锚点编辑、透视或三维摄像机。 |
| 预览直接操作 | 已实现 | 画面点选、拖动、四角统一缩放与旋转手柄，Shift 按 15° 对齐；一次手势一次撤销，Esc 取消。隐藏与锁定轨道不可操作，已有动画在当前时间补点。 |
| 原创效果库 | 已实现 | 19 种原创调色预设，另有模糊、像素化、暗角、绿/蓝幕、七种蒙版与镜像。参数实际进入预览和导出，未复制竞品 LUT。 |
| 效果栈与效果动画 | 部分 | 每片段保存一组效果参数；调色预设重置调色参数并保留蒙版/抠像/镜像等。尚无可排序多效果栈、效果参数关键帧、第三方 shader 插件。 |
| 基础调色 | 已实现 | 亮度、对比度、饱和度、色相、灰度、复古色、模糊、暗角。部分滤镜是 Canvas 参数预设，不宣称等同竞品色彩科学。 |
| 专业调色 | 待实现 | 色轮、RGB 曲线、HSL 分区、LUT 导入、示波器、HDR 管线与完整色彩管理。 |
| 动画预设 | 已实现 | 淡入淡出、缩放、平移、上升、弹入、旋转等 6 类预设，生成普通可编辑关键帧。 |
| 转场 | 部分 | 可以叠放两个片段并用透明度动画手工叠化。没有专门的跨片段转场对象、相邻片段余量处理或可拖放转场库。 |
| 几何蒙版 | 已实现，有限形状 | 圆形、矩形、椭圆、菱形、五角星、爱心、水平条带；大小、位置、旋转、羽化、反转。跟随片段变换；独立蒙版关键帧、钢笔路径、文字蒙版和跟踪待实现。 |
| 绿幕、蓝幕色度抠像 | 已实现 | 对选定背景色做颜色距离与透明度处理，可调容差。复杂毛发、溢色与运动边缘有限。 |
| 智能人物/物体抠像 | 待实现 | 尚未接入前景分割模型，色度抠像不属于智能人物抠像。 |
| 中文文字、标题 | 已实现 | 多行、字号、颜色、粗体、描边、背景、对齐，以及 4 类原创标题预设；输出为画面中的真实文字。 |
| 高级文字与字体库 | 待实现 | 用户字体导入、字体选择器、逐字动画、歌词高亮、路径文字、富文本、完整排版控制。当前依赖系统中文字体，跨系统字形可能不同。 |
| 手动字幕、SRT | 已实现 | SRT 导入后成为可编辑文字片段；SRT 输出支持时间码和多行文本。当前会输出工程中全部文字片段，包括标题，尚无字幕专用对象。 |
| 字幕高级格式 | 待实现 | VTT/ASS 导入导出、批量校时、样式轨道、逐词高亮、字幕翻译和说话人分离。 |

## 声音、变速与可选 AI

| 能力 | 状态 | 当前实现与边界 |
| --- | --- | --- |
| 多轨音频与导出混音 | 已实现 | 本地音轨、视频原声、音量与关键帧、淡入淡出、静音；导出按片段入点、起始位置、速度和轨道状态混音。真实短视频与采样检查覆盖延时、剪裁和混音。 |
| 左右声道 | 已实现 | 左右平衡、独立增益、原始立体声、仅左/仅右送到双侧、混合单声道、交换左右；16 组真实 Web Audio 与 FFmpeg PCM 对照通过。 |
| 本地原创音效库 | 已实现 | 16 种确定性合成音效，可试听、加入时间线，无网络或外部录音采样。生成音效 CC0，代码 GPL；不是网络素材商城。 |
| 常量速度 | 已实现 | 正向固定倍率，时长、源寻帧、字幕映射和音频导出按速度换算。导出通过 `atempo` 处理音频，不包含单独的音调开关。 |
| 曲线变速、倒放、定格 | 待实现 | 需要时间映射函数或预处理输出；尚无可用按钮或处理路径。 |
| 提取音频、波形、节拍 | 待实现 | 视频原声可混音，但无独立提取操作、真实波形计算、节拍检测或自动踩点。时间轴音频条纹只是类型提示。 |
| 降噪、响度、EQ、人声分离 | 待实现 | 没有把基础音量调节当成降噪或 AI 声音增强。 |
| 自动字幕：SenseVoice | 已实现，按需下载 | 中文优先；固定 INT8 ONNX 权重和 sherpa-onnx。Windows 真实 Electron 子进程中已识别中文自然语音和英语，需人工校对。 |
| 自动字幕：Whisper tiny | 已实现，按需下载 | 较轻量的替代模型；真实英语样本通过，中文误字较多。 |
| 自动字幕时间精度 | 部分 | 依据停顿与能量分段、句级估时，结合入点/速度/时间轴位置；没有逐字对齐或多说话人识别。 |
| 中文文本朗读 | 已实现，按需下载 | AISHELL-3 VITS，174 个音色；真实 26 字中文输入生成 5.69075 秒 WAV，可试听并加入时间轴。普通话为主，模型权重许可边界见单独文档。 |
| ChatTTS 自然配音 | 已实现，实验质量 | Windows 完整隔离安装、模型校验、自检、真实生成与媒体导入已通过；中文样本由 SenseVoice 转写并与输入逐字核对一致。音色和发音质量仍需试听；权重限非商业使用。Mac 推理待验证。 |
| 语音下载与任务状态 | 已实现 | 用户主动下载，体积说明、进度、取消、分段续传、完整散列校验、重试及有限本地诊断日志；安装后本机 CPU 推理。模型不随初始安装包分发。原用户 SenseVoice 故障未在测试机复现，不宣称已确定唯一原因。 |
| 声音克隆、数字人、脚本成片 | 待实现 | 没有接入这些模型或云端服务。 |
| 智能美颜、超分、补帧、修复 | 待实现 | 包括人脸精修、图像增强、物体消除、稳定、防抖、自动重构图、跟踪等，需分别实现和验收。 |

模型的固定来源、体积、许可、原生库兼容和实测样本见 [AI 模型说明](AI-MODELS.md) 与 [ChatTTS 说明](CHAT-TTS.md)。公开下载模型不自动等于允许任意商业使用；项目的 GPL 许可不改变模型本身的条款。

## 后续验收顺序

各版本的实际构建记录、对应源码提交与应用下载见 [GitHub Releases](https://github.com/Watertube-bilibili/freecut-desktop/releases)。0.3.0 新增预览直接操作、蒙版与调色扩展、原创音效/声道、下载恢复、自定义安装和自动更新；完整测试范围见 [验证记录](VERIFICATION.md)。

1. 先保证每个发布平台的导入、修剪、关键帧、保存重开、缺失重连、真实音画输出和取消路径通过，保存对应构建记录。
2. 完成可跨片段的转场、效果栈、音频波形/提取、稳定代理预览与崩溃恢复，降低日常剪辑摩擦。
3. 独立实现曲线变速、倒放/定格、钢笔蒙版与跟踪、LUT/曲线调色和多时间线。
4. 按模型许可、硬件需求、真实质量逐项接入智能抠像、跟踪、人声分离、修复和多机位，更新这一表中的具体证据。

只有完成真实输入、预览、工程保存与最终输出的闭环验证，才能扩大“已实现”的范围。
