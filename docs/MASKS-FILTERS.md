# 蒙版、调色与预览操作（0.3.0）

选中视频、图片、文字或色卡，打开右侧「调色 / 蒙版」。蒙版也可从左侧「特效」中直接选择。

- 七种形状：圆形、矩形、椭圆、菱形、五角星、爱心、水平条带。
- 大小为素材适配画布后的比例；位置 X / Y 为适配后的素材宽 / 高比例；旋转围绕蒙版中心。
- 羽化范围为素材短边的 0–25%，通过独立透明度图层混合边缘；「反转蒙版」保留形状外区域。羽化不会擦掉下方轨道。
- 蒙版会随片段的位置、缩放、旋转、透明度关键帧一起变化。蒙版本身的大小、位置和羽化目前是片段级静态参数，未提供独立蒙版关键帧、自由钢笔路径或智能跟踪。
- 19 个调色预设全部由亮度、对比度、饱和度、色相、黑白、复古和暗角的原创参数组合生成。切换调色预设会重设上一种调色的参数；蒙版、抠像、镜像和单独的模糊设置仍保留。

预览与逐帧导出调用同一渲染逻辑。羽化启用时需要额外的画布内存，大分辨率、多图层时会比硬边蒙版慢。预览选择框使用独立 DOM 覆盖层，不会写入输出画面。

短窗口布局为素材区、属性区和预览区各自提供滚动。左侧导航不会再撑高编辑工作区，右侧最后一项控件也不会落在时间线后面。手机布局打开底部素材架后，可在预览区滚动到播放和快捷操作按钮。

## 实现与素材来源

形状由本项目的数学路径生成；滤镜没有提取剪映或 CapCut 的 LUT、会员资源、代码或图标。官方公开功能页面用于确定常见编辑操作的范围，不作为素材库复制来源。

- [CapCut 官方蒙版说明](https://www.capcut.com/tools/mask-video-online)：公开介绍形状、位置、旋转、羽化和反转等操作。
- [CapCut 官方滤镜说明](https://www.capcut.com/resource/capcut-filter)：公开介绍生活、黑白、复古等调色类别。
- [CapCut 官方 Windows 编辑器介绍](https://www.capcut.com/resource/capcut-for-windows)：公开工作区和时间线示例；本项目保留自己的布局比例、配色、品牌和组件。

## 验证

```sh
npx vitest run src/core/masks.test.ts src/core/preview-transform.test.ts
npm run build
node scripts/regression-effects.cjs
node scripts/regression-transform.cjs
```

`regression-effects.cjs` 离线生成测试视频并在独立 Electron 配置目录运行，检查七种正反蒙版、羽化边缘像素、下方轨道、带变换关键帧的视频预览与严格导出像素一致、黑白切回彩色、原生工程保存，以及短窗口和手机布局底部控件是否被遮挡。它输出 JSON 报告和截图，失败会返回非零退出码。

这些测试验证列出的路径，不代表所有素材、显卡或编码格式的质量保证。
