# 水管剪辑 0.3.0 使用说明

这是开发预览版，先用短片熟悉编辑和导出。当前功能覆盖与限制见公开仓库的 `docs/FEATURE-MATRIX.md`。

软件全部功能永久免费，不设会员、不设付费解锁，导出无水印。爱发电为自愿赞助，是否赞助都能使用全部功能。第三方模型的版权许可说明使用范围，与软件收费无关。

## 选择版本

| 电脑或用途 | 下载文件 | 使用方式 |
| --- | --- | --- |
| Windows 10/11 x64，日常使用 | `FreeCut-0.3.0-win-x64-Setup.exe` | 自定义安装页面选择 C 盘、D 盘或自定义目录，安装后通过快捷方式打开。 |
| Windows 10/11 x64，免安装 | `FreeCut-0.3.0-win-x64-Portable.exe` | 放到可写文件夹直接运行。旁边的 `FreeCutData` 保存设置、最近项目列表和模型，移动时一起保留。 |
| Mac Apple 芯片（M 系列） | `FreeCut-0.3.0-mac-arm64.dmg` | 打开后把 FreeCut 拖入 Applications。 |
| Mac Intel 处理器 | `FreeCut-0.3.0-mac-x64.dmg` | 安装方法同上。 |
| Mac 压缩包 | `FreeCut-0.3.0-mac-arm64.zip` 或 `FreeCut-0.3.0-mac-x64.zip` | 解压得到对应芯片的 FreeCut.app；与 DMG 任选一种。 |

Mac 的「 → 关于本机」可查看芯片。普通用户只需下载一份应用包，不需要下载 `source` 源码归档。`SHA256SUMS.txt` 提供各文件校验值。

当前 Windows 没有配置发布者签名；Mac 使用临时签名，尚未经过 Apple 公证。请从项目的 GitHub Release 获取文件，并按下载页核对 SHA-256。

## 安装和更新

Windows 安装页面首次不选择磁盘。点“一键安装到 C 盘”会使用当前用户的 C 盘应用目录，页面显示完整路径；点“一键安装到 D 盘”会使用 `D:\FreeCut`。不存在 D 盘时该选项禁用。也可以点“自定义安装”选择可写目录；选到 `D:\` 等磁盘根目录时会自动补成 `D:\FreeCut`，禁止实际安装到根目录。

从旧 0.2.0 安装版升级时，新安装器不会直接认领旧安装目录。请从 Windows 设置卸载旧程序后安装，或另选一个新目录；保留原来的工程和素材。新版卸载只移除属于安装清单且未被改动的程序文件，保留用户项目、模型和未知文件。

“首页 → 设置 → 软件更新”默认启用自动检查、下载和安装。启动后及运行期间定时访问本仓库 GitHub Releases，匹配平台并验证 SHA-256。下载完成后，空闲时显示 20 秒安装倒计时，可点“稍后”；播放、导出或编辑弹窗忙碌时会等待。安装前有未保存修改仍会询问保存，取消或保存失败会保留工程。也可在设置中关闭自动更新或手动检查。

Windows 安装版更新原目录；便携版更新原便携文件并保留旁边的 `FreeCutData`。Mac 通过同架构 ZIP 更新，先把应用移出只读 DMG，放在可写的应用目录再使用。网络失败不会阻止继续剪辑，错误信息可在设置中查看。

## 从第一段视频开始

1. 启动后先进入首页，点击“新建项目”或“打开项目”。首次进入编辑器会显示三步引导，重点介绍左上角的电脑/手机图标，可随时切换“专业布局”和“手机风格”。
2. 点击“导入素材”，选择本地视频、图片或音频；双击素材或拖到时间线。
3. 选中片段，拖动两端修剪，在播放头位置分割。普通模式可使用画面和声音滑块；顶部切换“专业模式”后，可设置精确位置、缩放、旋转、音量、速度、淡入淡出和所在轨道。
4. 在“文字”中添加标题，或从“字幕”导入 SRT。基础效果、蒙版和色度抠像位于“特效”与“调色 / 蒙版”。
5. 点击保存，生成 `.freecut` 工程文件。工程引用原媒体，不复制媒体；请保留原文件。文件移动后可使用“重新链接素材”。
6. 点击右上角“导出”，选择分辨率、帧率、质量和保存位置，得到无水印的 MP4 视频。

手机风格把常用分类放在底部；关键帧和专业检查器仍可打开。检查器右上角叉号或 Esc 可以关闭检查器。

## 在预览中调整画面

点选预览里的视频、图片、文字或图形后，可以直接拖动位置；拖动四角调整大小，拖动旋转手柄改变角度，按住 Shift 旋转时按 15° 对齐。一次连续操作对应一次撤销，按 Esc 取消本次操作。被锁定或隐藏轨道上的对象不可拖动。

已经有关键帧的属性会在当前播放头位置更新或补充记录；没有关键帧时调整片段的基础状态。想做从 A 到 B 的动画，可以先在普通模式记录开始画面，再移动播放头、直接拖动对象并记录结束画面。

右侧属性区和左侧素材区分别滚动；小窗口中可滚动到最下方的控件。手机风格也可滚动预览区域找到播放按钮。

## 蒙版、调色和声音

“调色 / 蒙版”提供圆形、矩形、椭圆、菱形、五角星、爱心、水平条带，支持大小、位置、旋转、羽化与反转。蒙版跟随片段变换动画；当前没有独立的蒙版参数关键帧或跟踪。19 种原创调色可以直接切换，切换调色不会清除蒙版、抠像和镜像设置。

打开“音频”中的原创音效库，点试听，再加入时间线。16 种音效由本地代码生成，不需要登录或访问素材网站；生成 WAV 以 CC0 提供。视频原声和音频片段在基础属性中提供左右声道平衡、左右音量、仅左/仅右送到双侧、混合单声道与左右交换。源素材本身没有分开的左右内容时，选择声道不能凭空分离人声。

## 首页、设置和保存

“我的项目”显示最近保存和打开的工程，可搜索、排序、定位文件。点击工程卡片可继续编辑；从列表移除仅清除记录，不删除磁盘文件。旧版本工程通过“打开项目”导入记录，软件不会扫描你的磁盘。文件被移动时，可重新选择工程文件。

“设置”可选择默认工作台布局和关键帧模式，并查看本地数据目录、重新开启新手引导。“关于”提供版本信息、[作者的 B站主页](https://space.bilibili.com/390310418?spm_id_from=333.1007.0.0)及源码下载入口。

工程有未保存修改时，关闭窗口或退出应用会询问“保存并退出 / 不保存 / 取消”。返回首页、新建或打开另一个工程前，也可选择保存、放弃修改或取消。取消保存对话框、保存失败时会继续保留编辑器。保存的是当前工程数据，原媒体仍需保留。

## 关键帧

1. 保持顶部“普通（易用）”模式，选中片段，把播放头移到动画开始位置。
2. 点击“记录当前画面”（音频片段为“记录当前音量”），一键记住相关属性。
3. 移动播放头，拖动大小、左右、上下等滑块，再记录画面。播放时会在记录点之间自动过渡。
4. “上一处 / 下一处”可跳转关键帧，“删除此处”删除当前位置整组记录。也可直接点击“一键动画”中的缓慢放大、移入等效果。

需要逐项数值和缓动方式时，点击顶部或检查器的模式开关切到“专业”，再使用属性旁的菱形和关键帧列表。两种模式编辑同一份动画数据，切换模式不会清空关键帧。手机/专业布局开关与关键帧普通/专业模式相互独立。

已有动画或淡入淡出的片段分割后，会保留原变化并生成必要的边界关键帧；淡入淡出可能被合并为可编辑的透明度/音量关键帧。

## 自动字幕

1. 在时间线选中有声音的视频或音频片段。
2. 打开“AI 语音”中的“自动字幕”。中文优先选 SenseVoice；较小的替代模型为 Whisper tiny。
3. 首次点击“一键下载安装”，下载运行环境和模型。完成后选择语言，点击“识别字幕”。
4. 校对识别文字后点击“加入字幕轨道”。输出按句估计时间，复杂背景音、方言、快速语音可能需要人工调整。

SenseVoice 下载改为分段续传并做完整散列校验。下载后立即报错时，可在面板重试；会检查已下载文件，复用正确文件并重新获取损坏文件。界面错误会标明下载、校验或安装阶段，本地数据目录中的 `ai/diagnostics.jsonl` 保留有限诊断信息，不记录识别音频或朗读文本。该改进针对下载完整性和故障定位，不保证所有网络及系统环境均无错误。

## 语音朗读和 ChatTTS

1. 打开“AI 语音 → 语音朗读”，选择语音引擎。
2. AISHELL-3 提供较轻的中文朗读；ChatTTS 用于自然对话配音。
3. 首次点击对应的一键下载按钮。ChatTTS 会自动准备独立 Python、依赖和模型，并做真实语音自检；首次下载可能超过 2 GB，预留至少 6 GB 空间。
4. 输入文本、选择音色/语速，点击生成，先试听，再加入时间线。ChatTTS 每段最多 300 字，CPU 生成较慢，建议分段。

模型不随安装包分发。下载可以取消并重试，生成在本机执行，不上传音视频或文本。ChatTTS 官方模型采用 CC BY-NC 4.0，仅限非商业用途；其他模型也有自己的许可，请看下载面板和模型文档。Mac 的可选语音模型尚待对应设备验收。

## 当前边界

手机风格是桌面软件的布局，不是原生手机安装包。当前没有专门转场库、曲线变速、倒放、智能抠像、运动跟踪、代理媒体、完整高级调色或云协作。长片和 4K 的逐帧导出会占用时间与临时磁盘。建议先使用常见 MP4/H.264、PNG/JPEG、WAV/MP3 素材验证自己的工作流。
