# FreeCut — a video editor built by a junior high school student with GPT-6 and Codex

Hi, I'm 我叫水管同学. I built FreeCut using GPT-6 and Codex, and I'd love for you to try it.

FreeCut is an open-source desktop video editor for Windows and macOS. All features are free forever: no membership, no paid unlocks, and no export watermark.

Edit on a multi-track timeline, move and resize objects directly in the preview, record keyframes with one click, and switch between desktop and mobile-style layouts. It includes original effects and sounds, stereo controls, and optional local caption and voice models. It's still a development preview, and feedback helps make it better.

Download: https://github.com/Watertube-bilibili/freecut-desktop/releases

Read the English guide: https://github.com/Watertube-bilibili/freecut-desktop/blob/main/README.en.md

If you like the project, please give it a **Star on GitHub** and share what you make.

The app starts in Simplified Chinese. Select English in Home → Settings → Language or in the editor's top bar. Optional third-party models have their own licenses; ChatTTS's official model is non-commercial.
